A real Spring Boot 3.2 app — embedded Tomcat, @RestController, Jackson JSON — running entirely inside the wasm JVM. This page is an HTTP client that opens a TCP connection to the server running in the tab and speaks HTTP/1.1 to it. There is no network: the socket is a loopback stack living in wasm memory (bind/accept/poll/read/write emulated), so Tomcat binds 127.0.0.1:8080 and the browser dials it — all in-process.
