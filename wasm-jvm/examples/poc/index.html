Run a Swing app in the browser

A real OpenJDK-21 JVM (HotSpot Zero → WebAssembly) with AWT/Swing rendered to a full-viewport canvas. Pick one or more application .jars — its Main-Class runs and fills the window; keyboard & mouse work.

Pick individual .jars, or a whole app folder (its lib/*.jar + resources + classes go on the classpath, structure preserved). If no jar declares a Main-Class, type it above. The whole window becomes the app; reload to run another.
